No arquivo `index.html`, procure por:


Substitua pela URL real do Google Forms do cliente.

## 🎨 Personalizações Rápidas

### Alterar Cores
No `<style>`, procure por `:root` e altere as variáveis:
```css
:root {
    --primary: #1a1f71;    /* Cor principal */
    --secondary: #4338ca;  /* Cor secundária */
    --accent: #7c3aed;     /* Cor de destaque */
    --gold: #fbbf24;       /* Dourado */
}
```

### Alterar Textos
Todos os textos estão diretamente no HTML:
- Linha 233: Nome do evento
- Linha 234: Título principal
- Linha 236: Descrição hero
- Linha 244-254: Data, local, vagas

### Adicionar Imagens Reais
1. **Logo**: Linha 226 (substituir texto por `<img>`)
2. **Hero Background**: Linha 203 (adicionar imagem de fundo)
3. **Palestrante**: Linha 561 (substituir emoji por foto)

### Alterar Programação
Linhas 504-560: duplicar estrutura `timeline-item` e editar conteúdo.
